# Проверка после установки

Для полного прогона с готовыми данными используй [START_PRODUCT.md](../START_PRODUCT.md). Для публичного сервера проверь свои группы, услуги, данные и подключённые провайдеры.

| Раздел | Путь и проверка |
|---|---|
| Гостевой каталог | `/universities` → вуз → группа → неделя → пара. Открыть карту при наличии аудитории. |
| Вход и профиль | `/login` → пароль → кабинет → `/profile/access` → привязка и повторный вход. Сверить права на `/profile/sessions`. |
| Главная | `/` у студента, `/staff` у сотрудника. Онбординг, поиск, уведомления. |
| Расписание | `/schedule` и `/schedule/raspay`. День, неделя, месяц, фильтры, карточка и перенос сотрудником. |
| Импорт и обмен | `/calendar/import/photo` → свой JPEG или PNG → предпросмотр → поправить аудиторию → добавить → проверить неделю и `/calendar/export`. Проверить CSV, подписку и отзыв ссылки. |
| Карта | `/campus-map` → 1012 или 2018а → этажи и шаги → «К занятию». |
| Учёба | `/study/subjects`, `/tasks`, `/study/preparation`, `/study/timer`. Создать заметку, задачу и проверить таймер. |
| Оценки и учебный план | `/grades`, `/curriculum`, `/retakes` и разделы сотрудника. Проверить выбор дисциплины и результат пересдачи. |
| Учебные работы | `/staff/work` → создать и опубликовать → `/work` → сдать → проверить и вернуть результат. |
| Заявки и документы | `/requests` → справка → возврат на исправление → правка → выдача → `/documents` → PDF. Проверить доступ студентом B. |
| Финансы и проживание | `/finance`, `/residence`. Просмотр начислений, статуса, квитанции и бюджета. |
| Ресурсы | `/bookings`, `/equipment`, `/library`. Слот, очередь и отмена. У инвентаря проверить выдачу и возврат. |
| Афиша и билеты | `/campus-lab/events` → публикация → `/activities` → регистрация → календарь, билет, отметка входа и повтор. |
| Команды, клубы | `/teams`, `/clubs`. Приглашение, согласие, свободные окна и встреча. |
| Развитие | `/courses`, `/opportunities`, `/practice`, `/portfolio`. Сохранить прогресс, отправить отчёт и проверить ответ. |
| Вишка | `/assistant` → история, ссылки на свои сведения, результат модели и подтверждаемое действие. |
| Telegram | `/profile/telegram` → подключить чат → проверить код, «Сегодня», «Неделю» и уведомления → отключить. |
| Поддержка и настройки | `/support` → обращение → `/staff/support` → ответ. Сохранить оформление и проверить экспорт профиля. |
| Кампус Pay | `/campus-pay` → NFC или QR → покупка → чек → возврат → итоговый баланс. На кассе `/campus-lab/terminal`. |
| Кампус и справочник | `/campus-lab` → `/campus-directory` → контакт → кабинет и маршрут. Для учебного набора доступна `/campus-occupancy`. |
| Коворкинг | `/coworking` → линия замера → вход и выход → пауза → сверка и CSV. Геозону проверить на месте. |
| Эфиры | `/lectures` → трансляция → запись → очередь обработки → расшифровка → черновик и публикация работы. |
| Видеотека | `/lecture-library` → фильтры → избранное → главы → субтитры → продолжение → задачи. При подключённой модели сгенерируй личный конспект. |
