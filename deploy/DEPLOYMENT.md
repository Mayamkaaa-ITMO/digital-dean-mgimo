# Развёртывание на сервере

Приложение запускается через Docker Compose. Caddy обслуживает HTTPS, Gunicorn запускает приложение. Обработка лекций и напоминания выполняются в отдельных процессах. База SQLite и добавленные курсы сохраняются между обновлениями.

## Первый запуск

Понадобится Linux-сервер с Docker Engine и Compose v2, домен с DNS-записью на сервер и доступные TCP-порты 80 и 443. Сборка загружает зависимости для распознавания речи, OCR и, если выбрано, счётчика людей.

1. Распакуй архив. Из корня приложения скопируй файлы настроек.

   ```sh
   cp deploy/.env.example deploy/.env
   chmod 600 deploy/.env
   cp deploy/site.example.json deploy/site.json
   ```

2. В `deploy/.env` запиши свой домен в `DEAN_DOMAIN`. Укажи одно имя без схемы и пути. В `deploy/site.json` укажи вуз, часовой пояс, программы, группы, учебные периоды, дисциплины и услуги. Можно добавить контакты и расписание. Для занятия нужны `id`, `group`, `period`, `subject`, `from`, `to` и `kind`. Даты с временем принимаются в ISO 8601. Если не указать смещение, используется часовой пояс вуза. Поля `room` и `teacher` необязательны.
3. Собери образ, загрузи структуру вуза и выдай личные аккаунты. Команды используют идентификаторы из примера. При изменении JSON подставь свои значения. Команда выпуска попросит пароль в терминале.

   ```sh
   ./deploy/manage.sh build app
   ./deploy/manage.sh run --rm -T app python -m scripts.provision site - < deploy/site.json
   ./deploy/manage.sh run --rm app python -m scripts.provision account \
     --site university-site --login employee --name 'Имя сотрудника' \
     --role staff --group group-01
   ./deploy/manage.sh run --rm app python -m scripts.provision account \
     --site university-site --login student01 --name 'Имя студента' \
     --role student --group group-01 --period autumn-2026
   ./deploy/manage.sh run --rm app python -m dean staff-assigner --login employee
   ./deploy/manage.sh up -d
   ./deploy/manage.sh ps
   ```

4. Открой `https://<домен>/login`. Войди под созданными аккаунтами. Ответ `ok` на `https://<домен>/healthz` подтверждает доступ приложения к базе. Для эфира сотрудник с правом назначений указывает преподавателя, дисциплину, группу и период в «Управлении». У сотрудника есть доступ к закреплённым группам.
5. Пройди [проверку ролей и сценариев](FEATURES.md). Разделы, которым нужны занятия, справочники, ресурсы или записи, заполняются из данных вуза и через рабочие формы. Образец в видеотеке доступен сразу после входа.

## DeepSeek и провайдеры входа

Настрой провайдеров в `deploy/.env`. Привязка Яндекс ID или VK ID начинается в профиле после входа с паролем.

| Подключение | Настройки и проверка |
|---|---|
| DeepSeek напрямую | Задай `DEAN_AI_PROVIDER=deepseek` и `DEEPSEEK_API_KEY`. Стандартная модель `deepseek-flash`, переопределяется через `DEAN_DEEPSEEK_CHAT_MODEL`. |
| OpenRouter | Задай `DEAN_AI_PROVIDER=openrouter` и `OPENROUTER_API_KEY`. Модель чата меняется через `DEAN_OPENROUTER_CHAT_MODEL`, модель фото через `DEAN_OPENROUTER_VISION_MODEL`. |
| RouterAI | Задай `DEAN_AI_PROVIDER=routerai` и `DEAN_AI_API_KEY`. Модель чата меняется через `DEAN_ROUTERAI_CHAT_MODEL`. |
| Яндекс ID | В кабинете провайдера укажи возврат `https://<домен>/auth/yandex/callback`. Задай `DEAN_YANDEX_CLIENT_ID` и `DEAN_YANDEX_CLIENT_SECRET`. |
| VK ID | Доверенный адрес возврата `https://<домен>/auth/vk/callback`, идентификатор `DEAN_VK_CLIENT_ID`. |
| MAX | Задай `DEAN_MAX_BOT_USERNAME` и `DEAN_MAX_BOT_TOKEN`. Зарегистрируй мини-приложение на `https://<домен>/auth/max/miniapp`. |
| Ключ устройства | Управляется `DEAN_PASSKEYS`. В способах доступа добавь ключ и повторно войди на том же HTTPS-домене. |
| Telegram | Укажи `DEAN_TELEGRAM_MODE=polling`, имя, токен бота и разрешённые чаты. Запусти `./deploy/manage.sh --profile telegram up -d`. Затем привяжи бота внутри личного кабинета. |

При нескольких ключах провайдер текста задаётся через `DEAN_AI_PROVIDER`. При прямом DeepSeek фото обрабатывается локальным OCR либо отдельно настроенной моделью OpenRouter или RouterAI. После изменения файла настроек примени `./deploy/manage.sh up -d` и проверь ключ командой `./deploy/manage.sh exec app python -m scripts.check_ai_provider`. Команда делает один короткий запрос. `DEAN_AI_DAILY_LIMIT` и `DEAN_AI_TOTAL_LIMIT` задают лимиты запросов. Встроенная лекция, субтитры, конспект и задачи доступны до подключения модели.

Для проверки фотоимпорта загрузи `samples/weekly-timetable.png` и сверь дату, название, время и аудиторию перед подтверждением черновика.

### Вишка в Telegram

Настрой Telegram по таблице выше и запусти профиль `telegram` через Docker Compose.

По умолчанию используется `@mgimo_digital_dean_bot`. Токен читается из `dean-experience/.runtime/telegram.key` или вводится в скрытом приглашении терминала. Для другого бота задай `DEAN_TELEGRAM_BOT_USERNAME` и при необходимости `DEAN_TELEGRAM_BOT_TOKEN_FILE`. Для входа в личный чат используются одноразовая ссылка и код подтверждения, который студент вводит у себя в кабинете. Если проверка сообщает `poll_conflict`, останови другой запущенный процесс этого бота. При `webhook_already_set` переключи интеграцию с webhook на опрос только после остановки прежнего обработчика.

После запуска открой «Профиль → Telegram → Подключить Telegram», нажми «Запустить» у бота, затем введи полученный код на сайте. Для проверки открой «Сегодня» или «Неделя» в чате.

Для проверки Яндекса или VK зайди по паролю под личным аккаунтом. В «Способах входа» выбери привязку, пройди авторизацию у провайдера, выйди из приложения и войди новым способом. Проверь, что открывается тот же кабинет. Роли и группы назначаются внутри деканата.

Официальные инструкции по конфигурации [Caddy](https://caddyserver.com/docs/automatic-https), [DeepSeek](https://api-docs.deepseek.com/) и [OpenRouter](https://openrouter.ai/docs/api/api-reference/chat/send-chat-completion).

## Персональные данные

Страницы `/privacy` и `/privacy/consent` доступны без входа. Согласие оформляется отдельно и требует явного подтверждения после авторизации. При изменении текста приложение предложит подтвердить новую версию. В базе сохраняются точный текст, его версия и время каждого согласия и отзыва. [Статьи 9 и 18.1 закона № 152-ФЗ](https://www.consultant.ru/document/cons_doc_LAW_61801/).

Для демонстрационного стенда без опубликованных реквизитов оставь `DEAN_PRIVACY_REQUIRE_CONSENT=0` и используй вымышленные данные. Укажи параметры оператора и обработки в `deploy/.env` перед запуском кабинета с обязательным согласием.

| Настройка | Какие сведения указать |
|---|---|
| `DEAN_PRIVACY_OPERATOR`, `DEAN_PRIVACY_ADDRESS`, `DEAN_PRIVACY_EMAIL` | Наименование и адрес оператора, рабочая электронная почта по персональным данным |
| `DEAN_PRIVACY_AUTH_BASIS` | Законное основание для авторизации, ведения сеанса и защиты учётных записей |
| `DEAN_PRIVACY_RETENTION` | Сроки и условия прекращения обработки по целям |
| `DEAN_PRIVACY_PROCESSORS` | Наименования и адреса исполнителей и цели поручений либо подтверждённое отсутствие исполнителей |
| `DEAN_PRIVACY_TRANSFER` | Фактические условия передачи за рубеж либо подтверждённое отсутствие такой передачи |

После проверки текста оператором установи `DEAN_PRIVACY_REQUIRE_CONSENT=1` и пересоздай контейнер приложения. Если какое-либо из обязательных полей не заполнено, приложение сообщит об этом при запуске. Проверь, что политика открывается без входа, обычный вход ведёт на согласие, а отзыв из кабинета возвращает на этот экран и ограничивает дальнейший доступ к личным разделам.

До работы с реальными данными оператору нужно определить основания и состав данных по каждой цели, порядок обращения граждан, сроки хранения и удаления, меры защиты и порядок реакции на инциденты. Отзыв в кабинете фиксирует обращение и блокирует работу пользователя при включённом согласии. Оператор отдельно обрабатывает связанные запросы и применяет правила прекращения обработки и уничтожения данных. [Статьи 5, 6, 18.1, 19 и 21 закона № 152-ФЗ](https://www.consultant.ru/document/cons_doc_LAW_61801/).

При сборе данных граждан России проверь размещение используемых баз с учётом ч. 5 ст. 18. Проверь, необходимо ли уведомление Роскомнадзора до начала обработки по ст. 22 и отдельное уведомление до трансграничной передачи по ст. 12. Учитывай фактические места хранения резервных копий и передачи данных при работе внешних ИИ, провайдеров входа и мессенджеров. [Интерпретация ч. 5 ст. 18 Минцифры России](https://www.consultant.ru/document/cons_doc_LAW_511584/) · [Форма уведомления Роскомнадзора](https://pd.rkn.gov.ru/operators-registry/notification/form/) · [Статья 12 закона № 152-ФЗ](https://www.consultant.ru/document/cons_doc_LAW_61801/e4ebbe1780de623c7cf32a59ca82a7bb523a25dd/).

## Видео, OCR и камера

- В образе предусмотрены Tesseract с русским и английским языками, FFmpeg и локальный Whisper. `lecture-worker` берёт завершённые эфиры и добавленные записи из общей очереди, распознаёт речь и готовит PDF с конспектом и домашним заданием. После истечения блокировки обработчик автоматически повторяет прерванную попытку один раз. В карточке видно, на каком этапе обработка, а владелец может её остановить и запустить снова.
- В разделе «Лекции» выбери «Добавить лекцию» и укажи публичную HTTPS-ссылку либо загрузи MP4 или WebM до 64 МиБ. Обработчик ищет открытый файл в разметке страницы. `DEAN_LECTURE_PUBLIC_LINKS=0` ограничивает импорт хостами из `DEAN_LECTURE_IMPORT_HOSTS`. Для Wikimedia Commons и страниц W3C WAI достаточно указать хосты их файлов. Пустой список `DEAN_LECTURE_IMPORT_HOSTS` отключает импорт ссылок. Caddy разрешает до 65 МиБ для формы загрузки. База и каталог `/var/lib/dean/lectures` находятся в общем постоянном томе приложения и обработчика.
- Для ссылки на отдельное видео YouTube сборка использует `yt-dlp` и Node.js. Сохраняется аудиодорожка, из которой готовятся материалы лекции. Нужен исходящий HTTPS от обработчика к YouTube. Если площадка требует входа или сервер не может скачать запись, в карточке можно загрузить исходный файл.
- Встроенный курс находится в `dean/data/lecture_library/semantic-web/`. Для нового курса скопируй структуру примера, выбери уникальное имя каталога, замени метаданные, видео, WebVTT, главы, конспект и упражнения. Поддерживаются MP4 и WebM до 32 МБ на файл. Укажи автора, исходную ссылку и лицензию. Добавь пакет в `/var/lib/dean/lectures/` с правом чтения для приложения и перезапусти `app`. Для отдельной группы используй «Эфиры и записи группы».
- `DEAN_INSTALL_FIELD=1` и `DEAN_FIELD_REMOTE=1` включают детектор и получение кадров с браузера оператора по HTTPS. Из замеров сохраняются числа, время и результаты ручной сверки. Для настройки камеры сначала проведи репетицию у конкретной двери. Геозона задаётся в замере.
- В основной сборке «Загруженность аудиторий» доступна из «Сервисов» и «Бронирований». Шкала заполнения, свободные места, история и тепловая карта используют учебные данные. `DEAN_ROOM_OCCUPANCY_CAMERA=1` добавляет сотруднику возможность запустить камеру вручную.
- Campus Pay проводит покупки и возврат в учебных баллах. Физическую NFC-метку проверяй на поддерживаемом устройстве. Для официальных пропусков, начислений и подписанных справок используются интеграции вуза.

## Эксплуатация

```sh
./deploy/manage.sh logs --tail 100 app lecture-worker caddy
./deploy/manage.sh exec app python -m dean backup --to /var/lib/dean/dean-backup.sqlite3
./deploy/manage.sh cp app:/var/lib/dean/dean-backup.sqlite3 ./dean-backup.sqlite3
./deploy/manage.sh cp app:/var/lib/dean/lectures ./lecture-files
```

Перед обновлением сохрани резервные копии базы и файлов лекций в период без загрузок и обработки. При развёртывании в новую папку перенеси `deploy/.env` с правами `0600`. Проект Compose `mgimo-dean` использует те же тома базы, видео и сертификатов в каждой версии. Для обновления запусти `./deploy/manage.sh up -d --build`. Проверь `/healthz`, вход обеих ролей, обработку тестовой записи и скачивание обоих PDF. Один веб-процесс держит активные треки счётчика. Для нескольких реплик потребуется общий сервис трекинга.

Перед обновлением сохрани тег текущего образа. Для отката обновления со сменой схемы используй совместимую копию SQLite. Перед восстановлением копии сохрани изменения, сделанные после её создания.

При смене домена обнови DNS, `DEAN_DOMAIN` и зарегистрированные адреса возврата провайдеров входа. После запуска проверь `/healthz` и `/login` по новому HTTPS-адресу.

Архив для развёртывания можно собрать командой `python3 deploy/package.py /путь/к/архиву.zip`. Команда проверит целостность архива и выведет SHA-256. Активные настройки, локальные базы и ключи в архив не попадают.
