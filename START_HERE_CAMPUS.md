# Кампус · отдельная демоверсия

Для замера в коворкинге открой **start-coworking.command** и следуй [памятке для площадки](FIELD_TRIAL.md). В ней есть контроль проходов и сценарий для жюри.

На Mac распакуй архив целиком и открой `start-campus.command`. Терминал покажет адрес и собственные пароли этой копии. Страница кампуса открывается по адресу http://127.0.0.1:8096/campus-lab на том компьютере, где запущена команда. Остановить демку можно сочетанием Control+C в её окне. Для повторного вывода паролей выполни `./start-campus.command credentials` из распакованной папки.

Для проверки двух ролей открой обычное окно браузера и приватное. В первом войди как `student-a`, во втором как `staff`. Учётные записи, расписание и кошелёк сохраняются в папке этой копии. Для запуска нужен Python 3.12 или новее. Для записи лекций браузер запрашивает разрешение на микрофон. Студенческие учебные данные относятся к демонстрационной группе. Поэтажная карта кампуса доступна в разделе «Навигатор».

## Распознавание и модели

- Для новых лекций в локальном режиме нужны `ffmpeg`, `whisper-cli` и мультиязычная модель whisper.cpp. Укажи путь к модели через переменную `DEAN_WHISPER_MODEL` перед запуском. На авторском Mac стартовая команда находит установленную модель. Статус фоновой обработки виден в карточке. Можно закрыть вкладку и вернуться за результатом, пока запущено приложение. Длина обрабатываемой записи в этой версии — до 120 минут.
- Облачная расшифровка и составление материалов включаются раздельно в карточке лекции. Для прямого подключения OpenRouter задай `OPENROUTER_API_KEY_FILE` с путём к собственному текстовому файлу с ключом. Для RouterAI предусмотрен отдельный `DEAN_AI_API_KEY_FILE`. При обработке без языковой модели конспект составляется из фрагментов стенограммы, а домашние задания ссылаются на эти фрагменты.
- Для расписания по фото облачную модель можно выбрать при загрузке. По умолчанию работает локальное распознавание. Локальные варианты включают Apple Vision на macOS, Tesseract с русским языковым пакетом и распознавание ровных печатных строк на Python с Pillow. Для последнего можно задать `DEAN_OCR_PYTHON` с путём к интерпретатору с Pillow. У распечаток, фотографий под углом и таблиц с объединёнными ячейками проверяй каждую строку перед сохранением.
- Образец речи взят из официального проекта whisper.cpp. Встроенный готовый конспект учебного примера имеет собственную подпись. Для демонстрации обработки новой записи начни новый эфир.

### Как проверить физическую метку без публикации сайта

Подключи Android с NFC к Mac по USB. В Chrome на Mac открой `chrome://inspect/#devices`, выбери телефон и настрой Port forwarding с порта телефона `8096` на `127.0.0.1:8096` компьютера. Затем в Chrome на телефоне открой `http://localhost:8096/campus-lab`. В кабинете сотрудника запиши чистую учебную NDEF-метку, в кабинете студента считай её на экране покупки. Деньги на банковской карте в этом сценарии не используются. [Настройка USB-подключения и портов в Chrome](https://developer.chrome.com/docs/devtools/remote-debugging/local-server)

Подробный сценарий для независимого тестировщика находится в FULL_QA_PROMPT.md.
