# Контракт загруженности помещений, версия 1.0

В демо-кабинете с включённым флагом DEAN_EXT_ROOM_OCCUPANCY доступен GET /campus-occupancy?format=json&period=day. Периоды day и week задают последние 24 или 168 часов включительно по последнему наблюдению. POST /campus-occupancy из формы инициализирует набор синтетических наблюдений один раз.

| Поле | Значение |
| --- | --- |
| schema_version, source, timezone | Строки 1.0, synthetic и Europe/Moscow. Временные метки ISO 8601 в UTC. |
| period, updated_at, start_exclusive | Выбранный период, последнее наблюдение и исключённая левая граница. Для пустого набора updated_at равен null, start_exclusive отсутствует. |
| rooms[].room_key, label, floor, map_url | Устойчивый ключ существующей точки, подпись на плане, ключ этажа и маршрут от входа. |
| rooms[].capacity, latest, peak, average | Синтетическая вместимость, последний счётчик, максимум и среднее за период в людях. |
| rooms[].entered, exited | Суммы синтетических входов и выходов за выбранный период. |
| rooms[].parts[] | Подпись части суток и пиковая численность в этой части. При пропуске наблюдений peak равен null. |
| rooms[].forecast | at задаёт следующий час. value — медиана прошлых наблюдений того же часа для рабочего или выходного дня. samples — число наблюдений. method — historical_hour_median. |

Для слоя карты используется room_key. Цвет рассчитывается по доле latest / capacity или parts[].peak / capacity. Интерфейс таблицы использует пороги 40% и 75% и выводит численное значение. Для серии без наблюдений оставляется пустая ячейка. Контракт включает агрегаты по помещениям и времени.

GET `/campus-occupancy/live` возвращает текущий учебный снимок по ключам помещений. `source_kind` равен `synthetic` для исходного сценария и `demo_signal` после имитации прохода сотрудником. `recorded_at` содержит время последнего сигнала в UTC или `null` для исходного сценария. Поле `zones` задаёт девять ячеек зала c полями `label`, `count`, `capacity` и `level`. Исходный снимок и распределение по рядам моделируются. Сигналы учебного счётчика изолированы по организации аккаунта.
