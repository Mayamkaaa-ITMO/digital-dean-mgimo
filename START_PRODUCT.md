# Цифровой деканат

Из архива можно запустить две установки. Серверная установка принимает личные аккаунты, хранит данные и работает по HTTPS. Локальная установка с учебными данными предназначена для проверки сценариев. У каждой своя база.

На ПК и телефоне используется одна оболочка Raspay. На узком экране боковая панель открывается кнопкой меню. Порядок разделов, адреса и действия совпадают. [Итоговый прототип в Figma](https://www.figma.com/design/oYb7gy6eAR8NGI6U4FeEW0?node-id=265-30)

Лекции, практика, загрузка записи, загруженность аудиторий и голосовой чат вынесены в [дополнительные сценарии Figma](https://www.figma.com/design/oYb7gy6eAR8NGI6U4FeEW0?node-id=309-30).

## Быстрая проверка на Mac

Из папки после распаковки выполни `./start-demo.command`. Команда выводит адрес и пароли этой базы. Данные можно запросить повторно через `./start-demo.command credentials`. Для новой чистой проверки задай `DEAN_DEMO_NAME=review DEAN_PORT=8101 ./start-demo.command`. Учётные записи **student-a**, **student-b** и **staff** открывай в раздельных профилях браузера.

| Что проверить | Куда зайти | Как увидеть результат |
|---|---|---|
| Вход | `/login` | Наведи курсор на форму и переведи фокус в поле пароля. Вишка следит за курсором и отворачивается, когда вводишь или показываешь пароль. При настроенном VK ID или Яндекс ID проверь вход через провайдера на HTTPS. |
| Видеотека | «Лекции» → «Введение в семантический веб» → «Как веб описывает смысл данных» | Включи видео, выбери субтитры и нажми «Микроформаты и RDFa» для перехода на 3:41. В разделе «Конспект» открой PDF. Во вкладке с практикой проверь ответы и скачай домашнее задание. |
| Добавление записи | «Лекции» → «Добавить лекцию» в кабинете сотрудника | Выбери группу и загрузи MP4 или WebM со звуком либо укажи прямую HTTPS-ссылку на файл с разрешённого сервера. Дождись расшифровки, открой запись и скачай два PDF. Для обработки на Mac нужны `ffmpeg`, `whisper-cli` и путь к модели в `DEAN_WHISPER_MODEL`. В серверном образе они уже есть. |
| DeepSeek для видеотеки | Карточка лекции → «Подготовить мой конспект и задачи через DeepSeek» | После подключения модели появляются личные материалы к записи. Студент B под своим аккаунтом их не видит. |
| Вишка в кабинете | `/assistant` | Спроси, когда заканчивается бронь, открой карточку и сравни время. Попроси создать задачу, проверь предпросмотр, подтверди и открой список задач. Для проверки DeepSeek задай вопрос своими словами после настройки ключа. |
| Тепловая карта | «Сервисы» → «Загруженность аудиторий» | Сравни помещения по цвету, числу занятых и свободных мест. Проверь отметку «Демо» и историю за день и неделю. |
| Эфир, запись и учебная работа | «Лекции» → «Эфиры и записи группы» | Сотрудник создаёт эфир. Студент своей группы открывает эфир. После завершения сотрудник запускает обработку, проверяет конспект, создаёт и публикует учебную работу. Студент сдаёт её через «Учебные работы». |
| Остальные сценарии | [Проверка разделов и ролей](deploy/FEATURES.md) | Сценарии проходят на одной базе двумя ролями. Студент B проверяет ограничения доступа. |

## Публикация

В инструкции описаны Docker Compose, выпуск личных аккаунтов, настройка DeepSeek, Яндекс ID и VK ID, хранение базы и обработка лекций. Данные вуза и ключи провайдеров задаются при установке. [Инструкция для сервера](deploy/DEPLOYMENT.md)

Видео *Intro to the Semantic Web* — Manu Sporny. В приложение включена перекодированная копия с распознанными английскими субтитрами, русским переводом, новым конспектом и упражнениями.
